# Land Jobs with AI

Landing page for Johan Yamssi's YouTube channel. A single static `index.html`, hosted on Cloudflare Pages.

## Deploy
Cloudflare Pages, connected to this repo. Build command: none. Output directory: `/`. Every push to `main` goes live.

## Connect Kit
In `index.html`, set `KIT_FORM_ID` to the number from your Kit form's embed code
(`https://app.kit.com/forms/<ID>/subscriptions`). Until it's set, the signup button opens an email to johanyamssi@gmail.com.
